风险中心

账号登录态、平台条款、许可证与项目维护状态，是选型里最容易被忽略、代价却最高的部分。

三类最需要警惕的做法

  • 对抗平台风控：WJZ-P/douyin-upload-mcp-skill 使用反检测指纹伪装，是明确对抗风控的手段。
  • 明确违反平台条款：white0dew/XiaohongshuSkills 的多账号自动发布加互动；NanmiCoder/MediaCrawler 大规模采集法律风险最高。
  • 数据交给第三方：iamzifei/wechat-article-publisher-skill 走第三方代理鉴权，需把公众号授权给第三方。

许可证陷阱

  • AGPL 传染性：用于商业内容生产时要评估开源义务。
  • 禁止商用：部分项目采用 CC BY-NC 4.0，而自媒体场景多半是商业性的。
  • 声明与文件不一致：README 写 MIT 但仓库无 LICENSE 文件的情况需要单独确认。

停更与非标准形态

  • 用 skill.json 或 .skill 打包、缺 SKILL.md 的项目，装前通常要手改。
  • 独立 CLI / 桌面应用 / Web 服务不算 Agent Skill，需要自己包一层才能被 agent 调用。
  • 长期停更的项目强依赖平台网页结构或旧版规则，改版即失效。

ABOUT & DATA

关于 MediaStack

一个面向中文自媒体工作流的开源技能选型库。数据口径、字段定义与维护方式都在这里说明。

v2026.11

收录范围与数据说明

MediaStack 收录面向中文自媒体工作流的开源 Agent Skill、MCP Server 与配套工具，覆盖内容排版、文案选题、短视频播客、平台合规、数字人分身、数据分析与分发六个能力域。

每个项目按统一字段建档：能力描述、成本与风险备注、可用性分级、交付形态、热度、最近更新时间、安装命令。热度以 star 数表示，为收录时记录值，会随项目发展变化，请作为相对参考而非精确指标。

所有统计数字、分布矩阵与结果计数均由库内数据实时计算，页面与数据始终一致。我们会定期核验项目状态、更新可用性与维护情况，持续扩充收录范围。

收录以公开可检索的主流项目为范围，持续扩充中。页面内容与选型建议仅作技术参考，不构成法律意见。

字段口径与术语

开箱即用
装上就能跑，不需要任何 API key、不需要平台账号。
需 key / 依赖
需自备 API key，或需 ffmpeg / Playwright / Python 等本地依赖。
需登录态
需真实平台账号登录态（扫码、cookie），存在限流封号与平台条款风险，不建议用主号试。
停更 / 非标准
已归档、长期停更，或不是标准 SKILL.md 格式。
Agent Skill
含 SKILL.md 的目录，agent 按需加载的指令与脚本包，一般放 ~/.claude/skills/<name>/。
MCP Server
给 agent 提供工具接口的独立服务进程，配置到 MCP client，不是 skill 目录。
配套工具
CLI、桌面应用或独立服务，需自己包一层才能被 agent 调用。
路径差异
部分项目原生是 Codex skill（~/.codex/skills/），用于 Claude Code 需改路径。
